# 电影视觉升级验收记录

日期：2026-09-23。四部主影片、双犬动作及页面整合已完成，本记录区分本地实际验收与尚未实机验证的范围。

## 实现

- 保留生日邀请、精选相册、书信、生日愿望四章，以及主动启用摄像头、手动操作和全局静音。
- Snow / Rain 专业角色骨骼用于 24 秒原创双人舞；Autumn 犬模型用于两只陪伴犬的六组互动动作。来源与改编说明见 `public/ASSET_SOURCES.md`。
- Blender Cycles 输出角色、衣服、毛发、舞台、阴影与景深；生成的远景绘景作为背景。影片使用本地 H.264 / AAC，适配静态 GitHub Pages。
- 双人舞与草原故事各有独立的横屏、竖屏镜头；网页读取真实视频时间，统一管理暂停、静音和章节完成。
- 章节先准备下一页资源，遮幕完全盖住画面后切页，再揭幕；减少动态效果时直接切换。

## 实际边界

- 这是专业开源角色与离线渲染的风格化动画升级，不声称达到迪士尼长篇电影的角色表演、模拟或制作精度。
- 陪伴犬沿用 Autumn 的拓扑与体型，并非从零雕刻的精确贵宾犬；成年狮子仍由现有授权幼狮模型改编。
- 手机尺寸在 Chromium 中验收；实体 iPhone、Android 的解码、音频策略和耗电尚未实机验证。
- 本轮在本地完成开发；尚未推送仓库或部署线上 Pages。
